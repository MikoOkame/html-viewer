# HTML Viewer

HTMLを貼るか開くと、その場で表示するビューアです。編集も書き出しもこのページの中で完結します。

[https://mikookame.github.io/html-viewer/](https://mikookame.github.io/html-viewer/)

## 使い方

1. ページを開く。
2. 「貼る」でクリップボードのHTMLを入れる。または「ファイル」から `.html` / `.txt` を選ぶ。パソコンならウィンドウへドロップしても開く。
3. 「ソース」を開くと原文を直接直せる。少し止めるとプレビューに反映される。
4. 「書き出し」でHTMLファイルとして保存する。開いたファイル名が `.html` のときはその名前、貼り付けただけのときは `html-viewer.html`。
5. 「Undo」で一つ前の内容に戻る。「消す」の直前にも戻れる。
6. 「全画面」でバーを隠す。戻るときは「戻る」。

iPhoneでは「書き出し」が共有シートを開く。ファイルアプリへ保存できる。それ以外のブラウザではダウンロードになる。

ソース欄にいるときの Undo は、その欄の通常の取り消しが先に働く。バーの Undo は、貼り付け・ファイルを開く・消す・ソースの一区切りをまとめて戻す。

## ホーム画面

Safariの共有ボタンから「ホーム画面に追加」。アイコンを差し替えたあとは、古いアイコンを消してから追加し直す。

## できないこと

- HTMLの外にあるCSS、画像、別ファイルのスクリプトは読めない。本文に書いてあるものだけ表示する。
- 文字コードはUTF-8。Shift_JISのファイルは文字化けすることがある。
- ページを閉じると内容は残らない。残したいときは書き出す。
- 貼ったページのスクリプトは表示枠の中だけで動く。このビューア本体には触れない。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | ビューア本体 |
| `manifest.json` | ホーム画面への追加 |
| `apple-touch-icon.png` | iPhoneのアイコン |
| `icon-192.png` / `icon-512.png` | Androidなどのアイコン |
| `favicon-32.png` | タブのアイコン |
| `og.png` | SNSのシェアカード |
| `bird.png` | 画面中央の鳥 |
